# Smash Gun Duo

Smash Gun Duo est un jeu multijoueur local développé en Python avec Tkinter.  
Deux joueurs s'affrontent dans différents environnements, chacun contrôlant un personnage avec des armes différentes. Le premier joueur à atteindre 6 manches remporte la partie !

## Fonctionnalités

- Sélection du personnage et de l’arme pour chaque joueur
- Trois maps différentes :
  - Map 1 : Classic Battle
  - Map 2 : Vertical Strike (plateformes en hauteur)
  - Map 3 : Cyberpunk Fight (plateformes aléatoires et design futuriste)
- Déplacement, saut, traversée de plateformes et tir
- Système de vie et de manche
- Enregistrement automatique des scores dans `scores.txt`
- Possibilité de consulter ou réinitialiser les scores depuis le menu
